# Diagramm-Archiv

Hier liegen umfangreiche Diagramm- und Deliverable-Dokumente aus frueheren Projektphasen.

Enthalten sind:

- Sequenz-, Komponenten- und Paketdiagramme
- Mermaid-Indizes und Deliverable-Uebersichten
- zugehoerige Diagramm-Assets

Diese Inhalte bleiben erhalten, sind aber nicht mehr die kompakte Primaerdokumentation.
